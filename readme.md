#Linux and git cheat sheet

##ls 
Lists files and directories in the current directory

##cd
Changes the current directory

##i
vi command-Insert before cursor

##a
vi command-Append after cursor

##o
vi command-Open line below

##O
vi command-Open line above

##x file
vi command-Insert file after current line

##cw
vi command-Change word(Esc) 

##:wq
vi command-Write to file and quit

##init
Git command-initialize an existing directory as a Git repository

##clone [url]
Git command-retrieve an entire repository from a hosted location via URL

##add [file]
Git command-add a file as it looks now to your next commit (stage)

##status
Git command-show modified files in working directory, staged for your next commit

##checkout
Git command-switch to another branch and check it out into your working directory

##branch
Git command-list your branches. a * will appear next to the currently active branch

##branch [branch-name]
Git command-create a new branch at the current commit

##merge [branch]
Git command-merge the specified branch’s history into the current one

##log
git command-show all commits in the current branch’s history
